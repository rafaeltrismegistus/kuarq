# Modelo de validação

Use na mensagem de entrega, no commit ou no PR. Não precisa de arquivo por feature.

```text
O quê: <resultado observável, em uma frase>
Arquivos: <principais caminhos>

Verificado
- check.mjs: <passou/falhou>
- build: <compilou / não se aplica>
- Fluxo no app: <o que foi feito e visto>
- Temas: <claro / escuro / não conferido>
- Larguras: <larga / estreita (≤ 720 px) / não se aplica>
- Dados antigos: <como foi conferido / não se aplica>

Não verificado
- <o que ficou de fora e por quê>

Dados do usuário
- Backup antes de instalar: <arquivo / não instalado>
```
